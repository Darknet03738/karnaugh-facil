# Karnaugh Fácil

Herramienta web educativa para crear, convertir y simplificar mapas de Karnaugh de forma visual.

## Funciones

- Mapas de 2, 3, 4 y 5 variables.
- Edición desde mapa, tabla de verdad, expresión booleana, minitérminos o maxitérminos.
- Varias salidas independientes dentro de una misma tabla de verdad.
- Pestañas para añadir, renombrar, editar y resolver cada salida por separado.
- Valores `0`, `1` y condiciones *don't care* (`X`).
- Simplificación en SOP y POS.
- Agrupaciones explicadas paso a paso.
- Formas canónicas y tabla de verdad.
- Diagramas de circuitos AND–OR, NAND–NAND, OR–AND y NOR–NOR.
- Selector gráfico entre lógica normal y compuertas universales NAND–NAND/NOR–NOR.
- Conversión automática de la expresión mínima a Ladder (LD/KOP) y FBD (FUP/BDF).
- Contactos NA/NC, conexiones en serie/paralelo y bloques AND/OR explicados.
- Guía de estudio, errores frecuentes y checklist.
- Diseño adaptable a computadores y móviles.

## Uso

1. Elige el número de variables.
2. Selecciona la forma de entrada.
3. Introduce los valores de la función.
4. Elige SOP o POS.
5. Pulsa **Simplificar y explicar**.

La aplicación funciona completamente en el navegador y no recopila datos.

## Desarrollo local

Abre `dist/index.html` directamente o sirve la carpeta `dist` con cualquier servidor estático.
